# PH1A90SEG324：器件规格与板级证据边界

更新：2026-09-26。本项目采用的器件规格口径为 **PH1A90SEG324**，不是 PH1A90SBG484，也不是 PH1A60GEG324/C。本文是当前硬件规格的统一入口；开放问题只维护在 [UNKNOWN Registry](UNKNOWNS.md)。

## 1. 用户提供的规格证据

来源：用户于2026-09-26提供的两张产品规格表截图，读取两表中完整型号 `PH1A90SEG324` 的行。截图未附网页URL、文档版本或单位脚注；本轮不将其描述为新做的官网核验或板上实测。

- 接口表截图：`codex-clipboard-60c557a2-2e18-426a-8a25-b67244444aa8.png`。
- 资源表截图：`codex-clipboard-44b4e80b-73e4-418f-be50-5c988d8af103.png`。

| 项目 | SEG324截图值 | 解释与边界 |
|---|---|---|
| Device | PH1A90SEG324 | 项目器件规格基准；实物丝印、板卡版本和TD目标仍须交叉核对 |
| LUTs | 115776 | 不采用相邻SBG484行的115777 |
| DFFs | 128640 | 名义资源，不代表全部可供计算核心使用 |
| DistributeRAM | 1680K | RAM容量栏，不是1680个20K块；按bit容量口径解释，K单位脚注尚未提供 |
| eRAM-20K | 272 | 272个名义20 Kbit块 |
| eRAM-Total | 5440K | 272×20=5440 Kbit；按项目K=1024 bit预算口径为680 KiB |
| DSP | 240 | DSP数量不等于int8 MAC lane数量；实际映射需综合 |
| PLL | 12 | 板级时钟连接和实际可用频率另行验证 |
| Serdes-Channels | 8 | 器件通道数，不代表8路都接往RK3576或均可使用 |
| Serdes-Rate | 10.3125 Gbps | 器件速率规格，不是PCIe协商速率或端到端有效吞吐 |
| DDR-Rate | 1066 Mbps | 按每数据引脚传输率理解；不直接当控制器时钟MHz |
| DDR-Width | x16 | 器件规格所列外部数据宽度；不是DDR控制器内部用户接口宽度 |
| MIPI-IO | — | 表未列专用MIPI IO；不据此认定有硬MIPI接口，也不据此证明GPIO软实现绝对不可能 |
| USER IO | 148 | 封装用户IO规格；板上已占用、可引出数量需原理图确认 |
| 封装类型 | LFBGA324 | 不能复用SBG484的引脚、IO bank和约束 |

分布式RAM与ERAM是不同资源；不能不经映射验证就把二者相加，当成可任意替换的大容量ERAM buffer。680 KiB是沿用项目单位口径的名义值，最终还需TD的块数/模式/深度宽度利用率报告。

## 2. 与相邻SBG484行的区别

| 项目 | PH1A90SEG324（本项目） | PH1A90SBG484（不是本项目口径） |
|---|---|---|
| SerDes | 8路，10.3125 Gbps | 4路，12.5 Gbps |
| DDR | 1066 Mbps，x16 | 1066 Mbps，x40 |
| MIPI IO | — | 20 |
| USER IO | 148 | 280 |
| 封装 | LFBGA324 | LFBGA484 |
| LUTs | 115776 | 115777 |
| DSP / ERAM | 240 / 5440K | 240 / 5440K |

不能因为两者DSP/ERAM相同就沿用其通信能力、DDR宽度或约束文件。

## 3. 对预算与系统设计的影响

- **当前方案C**：240 DSP和680 KiB ERAM口径不变，但FPGA不再存完整权重/计算LM Head；原640+64 KiB超限仅属HISTORICAL full_fpga预算。Attention-only当前140+64=204 KiB是候选，不是综合证据；目标不用disRAM，不把其约210 KiB容量直接加进ERAM。
- **存储域**：用户板卡RK3576侧4GB LPDDR4X用于权重/CPU/NPU；FPGA侧DDR3L按256 MiB预算用于完整KV/metadata/buffers。RK内存不是FPGA直接DDR端口；方案C通过PCIe传tensor，不持续传完整权重。指南可能描述其他内存版本，实际容量仍须BOM/系统核对。
- **DERIVED（条件上限）**：若板上确为x16并达到1066 Mbps，引脚侧理论数据率为 `1066×10^6×16÷8=2.132×10^9 B/s`，即2.132 GB/s（十进制）。它不是已测DDR有效带宽，不计命令、刷新、仲裁、停顿或板级降速；不得自动填作预算脚本的实测带宽。
- **独立板级事实**：FPGA DDR容量沿用当前256 MiB预算，但截图没有提供DDR容量，不能由x16或1066 Mbps推导出来。DDR型号、容量、实配宽度和运行速率须由B/FPGA老师核对。
- **通信路径**：芯片8路SerDes不证明RK3576↔FPGA的PCIe lane数；现有指南的PCIe Gen2 x1线索仍须板级工程验证。MIPI不再作为已证实的可用替代通道，相关旧表述只算待核查线索。
- **工具/引脚**：TD器件选择、封装pinout、IO bank电压与约束必须匹配SEG324和实际板卡版本，不能照搬SBG484工程。
